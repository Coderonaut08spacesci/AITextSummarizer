# 📝 AI Text Summarizer (NLTK & Streamlit)

An extractive text summarization web application built with Python. The application allows users to paste long articles or upload `.txt` / `.pdf` documents to extract concise summaries based on word frequency analysis.

---

## 🌟 Key Features
* **Multi-Format Input:** Paste raw text or upload `.txt` and `.pdf` files.
* **Customizable Length:** Dynamic slider control to adjust summary output (1–10 sentences).
* **NLP Frequency Engine:** Uses NLTK for sentence tokenization, stopword removal, and word frequency scoring.
* **Clean Analytics:** Side-by-side metric comparison of original vs. summarized sentence count.

---

## 🛠️ Tech Stack
* **Language:** Python 3.10+
* **NLP Library:** NLTK (Natural Language Toolkit)
* **Web Framework:** Streamlit
* **PDF Parsing:** PyPDF
